# Agent 与本机 MCP 绘图接口

## 一、安装与启动

1、具有 MCP 接口的源码版本提供 `circuit-drawer-mcp` 命令。使用 Python 3.10 或更新版本安装可选依赖。在源码根目录运行下面的命令。

```powershell
python -m pip install -e ".[mcp]"
circuit-drawer-mcp --workspace "D:/Circuit Projects"
```

2、工作目录须已存在。服务通过标准输入输出与 MCP 客户端通信，客户端负责启动和关闭进程。出图默认写入工作目录的 `agent-output`，可用 `--output-dir` 指定工作目录内的其他位置。PDF 使用现有 LaTeX 工具，SVG 和 PNG 同时使用 Poppler。`capabilities` 返回本机可用格式。

3、采用 `command` 和 `args` 配置的 MCP 客户端可填写下面的服务器定义。请将 Python 路径与工作目录替换为实际位置，并将定义加入客户端对应的 MCP 配置区。

```json
{
  "command": "D:/CircuitEnv/Scripts/python.exe",
  "args": [
    "-m", "circuit_drawer.mcp_server",
    "--workspace", "D:/Circuit Projects"
  ]
}
```

4、外部客户端使用它自己的模型和 API 设置。MCP 服务执行本机图纸操作。编辑器内置 Agent 使用“AI 接口设置”中的模型与密钥，操作方法见第四节。

## 二、可调用的工具

| 工具 | 用途 |
| --- | --- |
| `capabilities` | 查询图纸类型、纸宽、导出格式和工具可用性 |
| `read_document` | 读取工作目录内已保存的电路或控制 JSON，返回图纸及候选 ID |
| `create_candidate` | 从完整坐标表建立候选，修改现有图纸时带上原候选 ID |
| `inspect_candidate` | 查看候选表、原文件位置、源版本和校验结果 |
| `edit_candidate` | 按字段路径修改候选，返回新候选及修改前后值 |
| `validate_candidate` | 使用现有电路／控制图检查器校验候选 |
| `save_candidate` | 将通过检查的候选另存为原文件旁的 JSON 副本 |
| `render_candidate` | 校验并导出 TeX、PDF、SVG、PNG，返回文件路径及 SHA256 |
| `simulate_candidate` | 执行 ngspice，返回实际波形、时间加权指标及运行记录 |
| `identify_modes` | 使用固定 PWM 工况识别开关模态，输出导通区间与模态图 |
| `analyse_loop` | 分析控制框图的穿越频率、相位裕度、增益裕度并导出波特图 |

1、读取、编辑、校验、保存、出图构成一次完整操作。每次编辑都返回新的候选 ID，后续操作使用新 ID。原候选仍可查询。源文件发生人工修改后，重新调用 `read_document` 可取得新的源版本。

2、`edit_candidate` 的每项修改由 `path` 和 `value` 组成。对象使用字段名，列表使用从零开始的整数索引。父对象须已存在，增加或删除列表成员时可替换整个列表。下面把现有仿真输入电压字段设为 48 V。

```json
{
  "candidate_id": "读取工具返回的候选ID",
  "changes": [
    {
      "path": ["simulation", "components", "Vin", "dc"],
      "value": "48"
    }
  ]
}
```

3、完整重画时调用 `create_candidate`，将新坐标表放在 `table`，将原候选 ID 放在 `base_candidate_id`。这样会保留原图的相对文件查找目录和源版本信息。校验失败的候选仍可查看、修改，保存及出图要求检查通过。仿真入口另外检查电气参数、器件支持范围与求解结果。

4、`save_candidate` 默认生成带内容摘要的文件名。也可用 `filename` 指定同目录下的普通 `.json` 文件名。已有不同内容时会要求换名，相同内容可重复保存。副本与源文件使用同一目录，控制表、波形数据等相对引用可以继续解析。随后可从 Circuit Drawer 启动器打开该 JSON。

5、导出结果分别放在独立目录中，成功结果带 `manifest.json`，记录候选版本、栏宽、原文件查找目录、校验和成品摘要。出图失败的暂存文件会被清理。候选保存在本次服务进程内，关闭服务前可先保存所需的 JSON 副本。

6、`simulate_candidate` 的 `window` 使用秒，`signals` 使用实际 CSV 列名或可唯一对应的探针名。省略区间时取数据末段 10%，指标按完整采样数据计算时间加权平均值、RMS、最小值、最大值及峰峰值。波形缩采样仅用于屏幕显示。结果的 `run_id`、图纸摘要、软件版本、时间区间、文件路径及 SHA256 写入 `run.json`。

## 三、与编辑器的接入约定

1、候选的 `revision` 是规范化坐标表的 SHA256，`source.revision` 是读取源图时的版本。编辑器接入时以采用前的当前文档版本作冲突检查，再将候选表送入现有采用与撤销事务。

2、MCP 读取已保存的文件。正在编辑的画布内容可由接入客户端作为完整表传入 `create_candidate`。内置 Agent 直接读取编辑器当前画布及其递增版本号。

3、两种入口共用 `circuit_drawer.agent_tools.AgentWorkspace`。MCP 协议层使用官方 Python SDK 的 stdio 服务，工具返回结构化 JSON。[官方 Python SDK](https://py.sdk.modelcontextprotocol.io/)

## 四、内置 Agent 的使用

候选卡可分别试算单栏与双栏。用「手动修改候选」在独立草稿补线、移标签，再保存、校验和采用。标签压线、压元件、互相重叠和留白过小均为可保留的提醒，候选可以直接采用、预览和导出。原图有改动时，以新版原图重新生成。


1、在电路或控制框图编辑器点击 **Agent**，选择空白画布或当前图纸。提示词库支持分类、搜索和折叠的“我的提示词”。从同一模板选“只画图”或“示例仿真”，点“填入需求（仍可编辑）”，改好文字后点“开始”。

2、“只画图”保留未填数值的符号。“示例仿真”先请你采用图纸，再按实际连接匹配示例工况，并补充参数建议。核对当前值、建议值、依据和假设，再采用工况以运行。即使沿用全部现值也需要确认。改变图纸的采用操作可撤销，点编辑器的“保存”写入 JSON。打开“仿真 → SPICE 仿真…”可继续编辑同一份参数，点待补项可跳到对应字段。

3、运行中可以继续编辑。每次运行关联开始时的图纸版本，手工改图后旧候选显示“基于旧版本”，采用按钮变灰。点击“按当前图重新生成”可取得新的候选。任务撤销仅在当前图纸与对应历史记录一致时提供。

4、结果抽屉展示实际求解波形、指标、模态区间及文件。波形默认放大到取样区间，可切换“完整波形”。已确认输出目标且有 `v_out` 测量时，摘要显示均值和目标偏差。固定频率、内部 PWM 工况还比较末尾八个周期的重复性，展开可查看漂移及阈值；采样过粗、时间不足或其他驱动工况会列明未核查原因。稳态判断仍需结合完整波形及工况。点击“在新标签页打开”可查看独立结果页。“打开波形窗口并绑定到图纸”复用现有波形编辑与导出功能，绑定时核对图纸版本。

5、“停止”会取消当前工作，已经完成的运行记录可继续查看。停止或失败后可从当前步骤重试。运行中的补充要求会在步骤边界处理，处理前可以撤回。API 鉴权失败、限流、求解错误和出图错误显示在任务卡片中。限流按照服务的 Retry-After 等待，最多自动重试三次。

6、Ctrl+Shift+A 打开并聚焦输入框，Enter 发送，Shift+Enter 换行。焦点位于候选卡片时，Ctrl+Enter 采用。Ctrl+. 停止，Esc 收起面板，F6 在画布、输入区与结果区之间切换。拖动侧栏或面板分隔条调整大小，也可用 Tab 聚焦后按方向键。双击或按 Enter 恢复单块，“恢复布局”还原当前编辑器的尺寸。窄窗改为单列，各区可滚动，折叠和恢复均保留输入。

7、任务历史属于当前编辑器服务会话。图纸旁的 `agent-output` 目录保存任务与运行记录，可下载 JSON、CSV 和图形文件。关闭服务前通过“保存”保存所需图纸。

8、能力列表按当前编辑器与已安装的工具显示。电路支持 ngspice、参数候选与固定 PWM 模态，控制框图支持环路分析。完整反馈控制图可通过 `circuit` 关联同目录已保存电路，采用后运行相应 ngspice 后端，或生成 Simulink builder／PLECS 模型。原生软件求解由用户在目标软件中执行。SPS ngspice 的适用条件见 SPS 说明。

9、参数生成沿用“先看结构”的思考强度，绘图沿用“生成／修改”的思考强度。参数候选列出具体值、单位、选择依据及模型假设，采用前可查看。追问追加到同一任务，保留原请求和已完成步骤。提示词库可以关闭后再次展开，已填写的值保留。

10、完整闭环可在控制图中一次描述并采用。先把功率电路保存到控制图所在目录，再说明文件名、反馈通道、参考值、PI 和调制设置。Agent 按实际连线生成绑定，将本次使用的完整电路保存为运行记录中的 `circuit-input.json`。结果中的模型导出项标明等待目标软件求解，可下载 builder 或模型继续操作。
