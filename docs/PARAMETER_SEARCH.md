# 参数范围与 Pareto 比较

1、选择 **实验功能 → 参数范围搜索…**，点击“读取当前可调参数”。也可在正在编辑的 SPICE 参数窗口中展开同名区域，保留窗口里填写的数值。选择参数、上下限、点数和线性／对数间隔；同一行可按 Ctrl 多选同步变化的参数，例如全桥四个开关的频率。各行取所有组合，总计最多 32 组。模块参数只修改允许编辑的实例覆盖值，不修改共用定义。

2、选择输出电压通道，填写非零目标直流电压和输出误差上限，可选纹波、过冲百分数上限。每组使用窗口中完整的瞬态时长、输出步长和最大积分步长，不截成短预览。每组最多 120 秒、一百万个预期输出采样点；超过预算、仿真失败或缺少数据会给出原因，不把不完整运行当成合格候选。

3、末尾八个完整 PWM 周期按相位对齐，检查电感电流、磁化电流、电容及目标电压的重复性；允许漂移取该通道纹波的 5%，并保留数值噪声下限。边沿时间由原始自适应积分点插值，周期核对保留包围边沿的实际采样区间。没有把“求解结束”当成“已经稳定”。未通过时，核对初值、积分步长和启动过程，再主动延长仿真。

| 指标 | 取值方式 |
| --- | --- |
| 输出均值 | 最后完整周期按时间积分，包含插值后的精确区间边界 |
| 输出误差 | `abs(均值−目标)/abs(目标) × 100%` |
| 纹波 | 最后完整周期的峰峰电压，除以目标电压绝对值 |
| 过冲 | 从仿真起点到终点，沿目标电压正负方向超出目标的最大值，除以目标电压绝对值 |

4、没有提供损耗数据时，比较纹波与过冲，两个指标均越小越好。蓝色点为 Pareto 候选：不存在另一合格候选在每个指标上至少相同、并在至少一项上更好。相同指标的候选会同时保留；Pareto 不表示已找到范围之外的最优解。图中只显示符合全部约束的结果，表格保留失败、未稳定和超限的每组原因。

5、点击图中的点或表格选项，再点“采用选中参数到窗口”。这一步只填写 SPICE 窗口；核对后点“保存参数”或导出才写入电路 JSON，并可按原流程撤销。图纸、窗口参数、搜索设置或数据文件变化后，旧候选不能采用。取消会终止正在执行的 ngspice 子进程，已经完成的证据保留；关闭窗口同样请求取消。若取消请求未送达，页面会提示后台任务可能仍在运行。

6、可填写“损耗与磁件数据文件”，路径相对于电路 JSON 所在文件夹。需要在运行编辑器的同一 Python 环境安装已取得的 powerdesignkit 包，且版本包含 `magnetics.calculate` 和 `operating.check(..., device_data=...)` 接口，例如：

```console
python -m pip install ./powerdesignkit
```

此时先按上述电压约束筛选，再比较**估算效率**与**磁件整件包络体积**：效率越高越好，体积越小越好。效率采用 `电阻负载功率 / (负载功率 + 所列模型损耗)`。不再把 SPICE 的开关导通损耗叠加一次；驱动器外部损耗与对侧开关附加损耗分别计入一次。

7、损耗文件格式为 `circuit-drawer.power-design/1`，完整例子见 [power-data.json](../examples/parameter_search/power-data.json)。文件引用路径相对于损耗文件自身；所有实际半导体、电感和电容都必须有对应条目，不填不等于零。

| 字段 | 内容 |
| --- | --- |
| `format` | 固定格式标识 |
| `source` | 所有输入的数据来源与条件说明 |
| `demo` | 必须明确填写；合成演示数据为 `true` |
| `load` | 一个电阻负载的实际元件 ID；模块内部使用 `实例/元件` |
| `devices` | 每个 nMOS／二极管的 `file` 和静态 `operating`；工况填写温度、驱动、统计列及明确的 `hard_recovery` 假设 |
| `magnetics` | 每个电感对应一组已给定磁件设计文件；每个扫描电感值必须且只能匹配一份设计 |
| `capacitors` | 每个电容的 `esr_ohm` 和适用频率、温度的 `source`；采用理想电容也要明确填写零及说明 |
| `auxiliary_watts` | 明确提供的辅助损耗，单位 W，可为零 |
| `current_threshold_a` | 体二极管导通电流判断阈值，单位 A，须大于零 |

8、开关频率、电压、电流来自本次波形，不能在 `operating` 另填一组数值。RMS 与二极管正向平均电流按完整周期积分；开通／关断电流取最后完整 PWM 导通平台首尾；阻断电压取该周期绝对峰值。powerdesignkit 使用给定温度或壳温迭代的手册近似模型，保留使用值和缺项说明。磁件按明确设计的线性电感、匝数和截面积求磁通，再算单回线 iGSE 和绕组损耗；超出材料频率、摆幅、偏置或峰值限值时拒绝估算。整件体积来自包括绕组、骨架的包络尺寸，不用有效磁芯体积替代。

9、损耗比较目前支持 V、R、L、C、二极管与 nMOS；GaN 第三象限、变压器、耦合电感、IGBT 及自动磁件选型尚未接入。普通电压指标扫描沿用定频开环理想开关与理想变压器模型，可用于普通图和模块图；不支持闭环、LEVEL=1 和非理想全图映射。损耗后处理与理想开关仿真分开求解，不会把损耗反馈到输出电压，也不代替额定值、热设计或实物校核。比较图中的体积不代表整台变换器。

10、独立演示使用 [Buck](../examples/parameter_search/buck.json) 和 [扫描设置](../examples/parameter_search/buck-search.json)：从零初值仿真 50 ms，扫描 400–600 µH 和 40–60 kHz，目标 12 V，误差 5%、纹波 1%、启动过冲 75%。较宽的过冲限值用于演示筛选，不是设计合格标准。器件文件、磁件尺寸／材料系数、温度和辅助损耗**全部是合成数据**，没有对应厂商选型。页面保留此标识及每项损耗。

```console
circuit-drawer parameter-search examples/parameter_search/buck.json --config examples/parameter_search/buck-search.json --out out/search
```

命令行只生成结果，不采用参数。扫描配置包含 `ranges`、`voltage`、`target_v`、`limits` 和可选 `power_file`；每条范围包含 `paths`、`min`、`max`、`count` 和可选 `spacing`（`linear`／`log`）。`paths` 从当前可调参数名中选择，普通元件形如 `simulation.components.L1.value`，模块形如 `modules.M.L1.value`。需要仅比较电压指标时，删除配置中的 `power_file`。

11、每次运行在独立 `run-*` 文件夹保存原图、配置和 `results.json`；每组有自己的参数表、网表、日志、原测量 CSV、压缩的原始器件积分点，以及成功检查后的周期数据／损耗明细。损耗与磁件源文件另存字节快照和哈希清单。结果表的详情显示该组文件夹，失败数据也保留，便于核对及重复运行。
