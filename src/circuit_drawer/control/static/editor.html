    操作与快捷键

    点选方块、连线拐点、文字或区域边框；Shift 点选可多选，空白处拖动可框选。拖方块时，相连的拐点跟着移动。双击连线可加拐点。

    Ctrl+S 保存，Ctrl+Z 撤销，Ctrl+Shift+Z / Ctrl+Y 重做，Ctrl+X 剪切，Ctrl+C 复制，Ctrl+V 粘贴（带连线、区域和传递函数，重名 id 自动加后缀），Delete / Backspace 删除，L 切换连线模式，Esc 取消连线或清除选择。

    方向键移动选中的方块或文字，按住 Shift 移动 5 倍吸附步长。滚轮缩放；“适应窗口”显示整张图。

    菜单支持方向键、Enter 选择、Esc 收起；点击画布也会收起。Mac 上可用 ⌘ 代替 Ctrl。
