  操作与快捷键
  
      左键拖空白处框选顶层元件、导线、自由文字、区域、方框和箭头，Shift 加框选追加；Shift 点选增减对象。拖动已选对象可整体移动，剪切、复制、创建副本、删除也对整组生效，一步撤销。贴合区域需连同全部成员移动；模块内部请进入定义编辑。
      R 旋转，F 镜像 / 反向，+ / - 调符号大小。Ctrl+X 剪切，Ctrl+C / Ctrl+V 复制粘贴，Ctrl+D 创建副本，Ctrl+Z 撤销，Ctrl+Y / Ctrl+Shift+Z 重做，Delete / Backspace 删除。
      画导线时单击加拐点，双击或 Enter 完成，Esc 取消。滚轮缩放，中键或按住空格加左键拖动平移；[ / ] 切换模态。
      
  
      选中一个对象或一组对象后，方向键移动一个网格（0.05 布局单位），Shift 加方向键移动 10 格；元件相连的导线跟随调整。单选导线折点时移动折点，选中线段时只沿垂直方向微调。输入框、菜单和弹窗内的方向键仍操作对应控件。
      
  
      右键元件、导线、模块或标注打开对应动作菜单；右键已选对象保留整组操作。空白处可按鼠标位置粘贴或插入。上下键选择、Enter 执行、Esc 关闭，左右键进入／返回子菜单；变灰项悬停说明原因。颜色、字号和尺寸仍在属性栏。
      
  
      右键元件可添加现有仿真支持的电压／电流／驱动测量，并打开测量通道确认；导线对地电压需先保存参考地。右键引脚可切换故意悬空，四路交叉处可切换相连／跨线。“相关问题”沿用问题栏的定位和允许的意图声明。
      
  
      已有导线：双击线段加折点，拖动横竖线段时保留首尾位置。单击小圆点后 Delete 删内部折点；属性页可拆分、合并和删除整条线。重叠处再次单击轮换导线，问题栏也可逐条选择或删除完全重复线。
      
  
      区域、方框和箭头：右键或“编辑 → 同类对象图层”可上移一层、下移一层、置顶、置底。Ctrl+] / Ctrl+[ 上移／下移，加 Shift 置顶／置底。普通色块不跨到电路上方；前景块箭头仍由其外观选项控制。
      
  
      菜单支持方向键、Enter 选择、Esc 收起；点击画布也会收起。Mac 上可用 ⌘ 代替 Ctrl。
      
  
      器件库可以点击或拖入画布；分类标题可收起，搜索会显示匹配项。阶跃 / 脉冲标记在“插入”菜单。
      
  
      网表记录哪些引脚应该相连。只有有意改接线后，才使用“分析 → 以当前连接更新网表”。模态页按开关状态高亮电流回路，箭头表示电流方向。
